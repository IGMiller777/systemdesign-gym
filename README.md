# SysDesign Gym

LeetCode-style тренажёр проектирования систем: задачи от простых оценок до полного дизайна, мгновенная проверка и ИИ-интервьюер.

## Запуск

```bash
pnpm install
pnpm dev        # web: http://localhost:5800, grader API: :5801
```

ИИ-проверка дизайна идёт через локальный Claude Code CLI (`claude -p`), без API-ключа. Модель: `GRADER_MODEL=opus pnpm dev` (по умолчанию `sonnet`).

## Уровни задач

| L | Тип | Проверка |
|---|-----|----------|
| 1 | Оценка на салфетке | мгновенно, число в пределах ×factor |
| 2 | Выбор блока / подхода | мгновенно, с объяснением каждого варианта |
| 3 | Найди узкое место | мгновенно, клик по блоку схемы + графики метрик |
| 4 | Инцидент | ИИ по рубрике |
| 5 | Дизайн сервиса | ИИ по рубрике + уточняющий вопрос |
| 6 | Босс | ИИ по рубрике + уточняющий вопрос |

Прогресс (XP, серия, лучшие результаты, черновики, ИИ-сценарии) хранится в localStorage.

## Дежурство и песочница

Математический симулятор (`src/sim/engine.ts`, тесты: `pnpm test`): у каждого блока ёмкость, задержка, цена, способ масштабирования и прогрев. Загрузка ρ → задержка `base / (1 − ρ)`, при ρ ≥ 1 — таймауты и ошибки `1 − 1/ρ`. Кэш, реплики, очереди, CDN и rate limit меняют поток; failover Postgres через 1 минуту при наличии реплики; DDoS-мусор rate limit режет первым.

- **Дежурство** — 8 сценариев-цепочек инцидентов: 1 с = 1 минута, бюджет ошибок (здоровье), бюджет $/мес, разбор после игры и ИИ-постмортем. Каждый сценарий проверен ботом: без действий — проигрыш, с правильной стратегией — победа.
- **Песочница** — без таймера: крути нагрузку, роняй блоки.
- **ИИ-сценарии** — генерация по теме и сложности; сервер прогоняет сценарий движком и перегенерирует, если он непроходим или слишком лёгкий.

## Справочник — колода карточек

30 коллекционных карточек (`src/wiki/cards-*.ts`): эмодзи, редкость, характеристики (скорость/масштаб/надёжность/цена/сложность), суперсила и слабость, бытовая аналогия, TL;DR, история из прода, инфографика типичной схемы, радар со сравнением, квиз из 3 вопросов (2/3 → карточка освоена, +20 XP). Технические детали (`src/wiki/entries.ts`) — под «Подробнее». Под карточкой — вопрос ИИ-наставнику.

## Тренировка дня, дуэли, «Объясни сам»

- **Тренировка дня** (`/daily`): интервальное повторение (1/3/7/21/60 дней) + свежий микс — вопросы карточек, оценки, дуэли, «объясни сам». +30 XP за день.
- **Дуэли** (`/duels`, `src/duels/`): 30 ситуаций «что выбрать» (бэкенд + фронтенд-архитектура), с ценой выбора и условием, когда победил бы другой.
- **Объясни сам** (на странице карточки и в тренировке): объясняешь аспект своими словами (суть, плюсы, минусы, когда не брать, что сломается, масштабирование, сравнение) — ИИ сверяет со справочником (`/api/explain`).

## Наследство

`src/sim/inherited.ts`: первый день в компании, инфраструктура есть, но настроена неправильно. Топология и железо заморожены — меняются только настройки (`Knobs`: TTL кэша, maxmemory-policy, индекс, пул соединений / max_connections, таймауты, потоки, ретраи, партиции Kafka). В инспекторе — фрагмент реального конфига с подсвеченными строками. Каждый сценарий проверен ботом: без исправления падает, с исправлением на 3-й минуте выживает; «очевидные» ложные фиксы (например, поднять max_connections) не спасают.

## Игровой слой

- **Кредиты** 🪙: 1 XP = 1 кредит, плюс квесты и достижения. Тратятся в магазине (`/shop`) на перки (ИИ-напарник, кофе-брейк, быстрый деплой в дежурстве; второй шанс в квизе) и косметику (темы холста, голографические карточки).
- **Квесты дня** (3 в день + сундук), **достижения** (~28, часть секретные), тосты с конфетти, повышение звания. Логика — `src/game/` (наблюдатель за прогрессом, без циклических импортов в стор).

## Безопасность (`/security`)

- **Blue Team** (`src/defense/`): tower defense — ставишь защиты по зонам (периметр, приложение, данные, ИИ-агент, зависимости, люди) в пределах бюджета, волны атак проходят по зонам, каждая защита с вероятностью блокирует. 22 защиты, 16 атак, 6 уровней, эталонные наборы проверены тестами (≥90% блокировки).
- **Взломай агента** (`server/ctf.ts`): prompt-injection CTF в духе Gandalf, 6 уровней защиты (промпт → фильтр ответа → ИИ-судья → фильтр ввода → косвенная инъекция через письмо). Пароли только на сервере.
- Уроки и дуэли по безопасности, модуль в пути обучения.

## Хардкор

`src/sim/hardcore.ts`: тот же инцидент, но очевидный блок запрещён с правдоподобной причиной (аудит ИБ, релиз-фриз, ушедший провайдер). Открывается после победы в обычной версии; каждый проверен ботом на проходимость альтернативным путём.

## ИИ

Все ИИ-функции идут через локальный `claude -p` (без инструментов, без MCP, без сохранения сессии): `server/claude.ts`.

| Endpoint | Что делает |
|---|---|
| `/api/grade` | оценка дизайна по рубрике (JSON-схема) |
| `/api/ask` | ответ наставника в справочнике |
| `/api/postmortem` | постмортем по таймлайну метрик и действиям игрока |
| `/api/scenario` | генерация сценария дежурства + плейтест движком |

## Добавить задачу

Задачи — типизированные объекты в `src/tasks/*.ts`, типы в `src/tasks/types.ts`.

## Структура

- `server/` — Hono API (порт 5801), промпты по файлам
- `src/sim/` — движок, сценарии, игровой цикл, дашборд
- `src/wiki/` — справочник
- `src/components/InstantViews.tsx` — L1/L2
- `src/components/BottleneckView.tsx` — L3 (React Flow + Recharts)
- `src/components/DesignView.tsx` — L4–6: пошаговая форма + холст
