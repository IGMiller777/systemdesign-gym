## Коротко

- **Что:** русскоязычный тренажёр system design в стиле LeetCode + игра. 56 задач, 41 урок, 37 карточек справочника, 52 дуэли, 30 сценариев дежурства, 10 mock-интервью, игра Blue Team и prompt-injection CTF.
- **Как:** SPA на React 19 + Vite (порт 5800) и маленький API на Hono (порт 5801). Все ИИ-функции идут через локальный `claude -p` (Claude Code CLI) без API-ключа.
- **Сердце:** детерминированный симулятор нагрузки `src/sim/engine.ts` (модель очереди M/M/1 на графе блоков), покрытый тестами.
- **Состояние:** весь прогресс игрока хранится в zustand-сторе, синхронизируется в `data/sysdesign-gym.json` через API (с ежедневными бэкапами) и дублируется в localStorage.

## Быстрый старт

```bash
pnpm install
```

```bash
pnpm dev
```

Откройте http://localhost:5800. Подробности в [07-instructions.md](07-instructions.md).
